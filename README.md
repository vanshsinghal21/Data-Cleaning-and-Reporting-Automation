# Data Cleaning & Reporting Automation

This project automates the process of cleaning sales data and generating business reports using Python. The workflow removes duplicate records, handles missing values, creates a cleaned dataset, and generates visual sales insights through automated charts.

## Features

- Automated data cleaning
- Duplicate removal
- Missing value handling
- Sales performance analysis
- Automated report generation
- Data visualization using Matplotlib

## Technologies Used

- Python
- Pandas
- Matplotlib

## Outputs

- Cleaned dataset (`cleaned_data.csv`)
- Automated report (`report.txt`)
- Country-wise sales chart (`country_sales.png`)
- Product line sales chart (`productline_sales.png`)

## Learning Outcomes

- Data preprocessing
- Workflow automation
- Reporting efficiency
- Business data analysis
